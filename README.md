# TetrisEffectArchipelago
Archipelago randomizer mod for Tetris Effect: Connected.

This mod is currently in development and is not functional. You can however keep track of it's progress here
Whenever a playable release is available, you will see it in the [AP World repository](https://github.com/ZatchyBeeps/Archipelago-TEC)

The mod requires a blueprint helper, located on Scripts/BModManager/TetrisEffectArchipelago.pak which needs to be placed in <SteamLocation>/steamapps/common/Tetris Effect Connected/TetrisEffect/Content/Paks/LogicMods
